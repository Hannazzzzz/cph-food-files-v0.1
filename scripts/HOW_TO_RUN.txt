RESTAURANT HARVESTER v2 - SIMPLE INSTRUCTIONS
=============================================

WHAT IT DOES
Visits each Google Maps link in your CSV and writes an enriched CSV with:
address, neighbourhood (from postal code), coordinates, rating, review
count, price level, phone, website, opening status, and whether the place
is permanently or temporarily closed.

WHAT IT ACCEPTS AS INPUT
- A Google Takeout export (Title,Note,URL,... columns), OR
- A previous enriched CSV (re-scrapes and refreshes every place).
Comma or semicolon delimited, with or without Excel quirks - it copes.

MANUAL TAGS ARE SAFE
food_tags and mood_tags you added by hand are preserved on every re-run,
matched by the Google place ID (so renames and duplicate names are fine).

HOW TO RUN (Mac)
1. Open Terminal
2. cd ~/Documents/"Restaurant Guide"        (or wherever your CSV lives)
3. ./RUN_ME.sh "Favorite_places_march_2026.csv"

   Or directly:
   python3 harvest_restaurants.py "Favorite_places_march_2026.csv"

   Quick test with only the first 3 places:
   python3 test_run.py "Favorite_places_march_2026.csv"
   (writes to *_test_results.csv, leaves your real data alone)

   Limit a full run:
   python3 harvest_restaurants.py "input.csv" --limit=10

OUTPUT
- input "X.csv"           -> output "X_enriched.csv"
- input "X_enriched.csv"  -> refreshed in place
- Output is always comma-delimited UTF-8 (what the website expects).
  If you edit it in Excel, save as CSV UTF-8 - but the scraper copes
  either way.

RELIABILITY
- One failing place never stops the run: it's recorded as an error in the
  status column and the run continues. Re-run the same command to retry.
- If the FIRST 3 places all fail, the run aborts - that means something
  systemic (usually a Google consent wall or page redesign). Check
  harvest.log and tell Claude.
- Progress is saved after every single place, so interrupting is safe.
- At the end you get a summary: succeeded / failed / permanently closed /
  temporarily closed.

TESTING WITHOUT A BROWSER
python3 tests_offline.py    (21 unit tests, no network needed)

TROUBLESHOOTING
"Chrome not found"  -> install Google Chrome
Everything fails    -> check harvest.log, likely consent wall; re-run once
A place fails       -> its row has status "error: ..."; re-run to retry;
                       successful rows keep their data and tags either way
