Recommended Usage (current multicolour design)

Electric Pink (#FF1493): FOOD filter button and base of the FOOD tag family
Dark Purple (#2E1A6B): MOOD filter button
Orange (#FF8A00): HOOD filter button
Sky Blue (#00B3E1): Signup Send button
Gold (#FFD700): All map pins and clusters
Deep Orange (#FF4500): Hover and active accent, link hover
Blue (#1E90FF): Links
Black (#000000): Text, borders, outlines (1px thin borders)
White (#FFFFFF): Page background. Light Grey (#F2F2F2): row hover, map placeholder
Tag colours: every filter tag has its own colour within its category family (FOOD violet to pink, MOOD cyan to blue to indigo, HOOD orange to yellow). See src/lib/tagColours.ts and the Tag Colours section of the UI style guide.
